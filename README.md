# Swansway Marketing Portal

Multi-page marketing planning portal for Swansway Motor Group.

## Pages
- `/` — Group overview (KPIs, calendar, channels, priorities)
- `/brief` — Brief Builder (6-step wizard + campaign mode)
- `/brand` — Brand pages (dynamic by brand)
- `/campaigns` — Campaign board
- `/intel` — Autopsy, competitor scan, training

## Stack
- Vercel (hosting)
- Supabase (database + auth)
- Vanilla JS + CSS (no framework)

Built: June 2026
